# KU-TaP — เครื่องมือสร้างตารางเรียน

เว็บไซต์สำหรับจัดตารางเรียนรายสัปดาห์และส่งออกเป็นไฟล์ PNG, JPG หรือ PDF แนวนอน พัฒนาด้วย Vue 3, TypeScript, Tailwind CSS และ Pinia

## เกี่ยวกับเว็บไซต์

เว็บไซต์นี้เป็นเพียงการสร้างตารางการเรียนเพื่อวางแผนและจัดตารางเรียน เป็นการทำงานลวก ๆ และไม่ได้เชื่อมต่อฐานข้อมูลใด ๆ ดังนั้นเพิ่มรายวิชาเอาเอง นะ จ๊ะ จุ๊บ ๆ

(และอย่ากดรีหน้าจอหากเขียนไปแล้ว เพราะมันไม่เซฟนะจั๊บ)

ข้อมูลรายวิชาและการตั้งค่าจะอยู่ในหน่วยความจำระหว่างใช้งานเท่านั้น เมื่อรีเฟรชหรือเปิดเว็บไซต์ใหม่ ข้อมูลจะหายไป และไม่มีการบันทึกลงบัญชีผู้ใช้หรือพื้นที่จัดเก็บของเบราว์เซอร์

## ความสามารถ

- กำหนดเวลาเรียนได้ละเอียดทุก 30 นาที
- ปรับช่วงเวลาในตารางให้อัตโนมัติตามรายวิชาที่เพิ่มหรือลบ
- จัดการรายวิชาที่เวลาเรียนซ้อนกันด้วยการแยกแถวในวันเดียวกัน
- เพิ่มตาราง Lab เป็นส่วนหนึ่งของรายวิชาได้ โดยแต่ละวิชามี Lab ได้หนึ่งชุด
- เลือกใช้ธีมสีได้ 6 รูปแบบ
- รองรับภาษาไทยและภาษาอังกฤษ พร้อมรูปแบบการแสดงเวลา 12 ชั่วโมง, 24 ชั่วโมงสากล และ 24 ชั่วโมงแบบไทย
- ส่งออกตารางเป็น PNG, JPG หรือ PDF แนวนอนขนาด A4
- ไฮไลต์รายวิชาในตารางเมื่อชี้เมาส์ที่รายวิชาในรายการ และในทางกลับกัน
- แสดงช่วงพักกลางวันเวลา 12:00–13:00 น.

## โครงสร้าง

อัลกอริทึมจัดการเวลา การตรวจสอบเวลาซ้อน การคำนวณช่วงตาราง และการตรวจสอบความต่างสี อยู่ในฟังก์ชัน TypeScript ภายใต้ `src/lib/` และมี unit tests ครอบคลุม
